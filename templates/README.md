# Configuration Files

This folder contains the following configuration files:
- `electron-builder.env` - stores the certification credentials for the build script
- `electron-vite.config.ts` - updated to enable shadcn/ui plugin
- `tsconfig.json` - updated to enable shadcn/ui CLI
- `tsconfig.node.json` - updated to make Electron aware of `src/shared` folder
- `tsconfig.web.json` - updated to make Electron aware of `src/shared` folder and enable shadcn/ui plugin
